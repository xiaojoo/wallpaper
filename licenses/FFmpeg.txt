FFmpeg used by Wallpaper
=======================================

This file is generated by tools/ffmpeg-notice.sh from the libraries that are actually in the

What we use it for
------------------
  Demuxing and decoding video wallpaper files (libavformat + libavcodec). The code that calls
  it is Engine/Graphics/FFmpegPlayer.cpp. No FFmpeg source is copied into this project; the
  library is used through its public headers and linked as shared DLLs.

Replacing the library
-------------------
  WallpaperRenderer.exe loads these DLLs by name at process start and calls nothing else from
  them, so you may swap any av*-*.dll / sw*-*.dll in the program folder for another build of the
  same library. That is the point of linking dynamically: the relinked version runs, and the
  log and `--ctl status` print whichever build was actually loaded.
